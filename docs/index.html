Phase 1: Implementation Milestones

ViDo builds one reviewable slice at a time. Each milestone ends at a strict review gate:

M0 · Product Discovery COMPLETED

Vision, audience, universal principles, core task flow, living brief, and handoff specifications.

M1 · Static Visual Foundation COMPLETED

Vite + React + TS architecture, design system tokens, public landing page, and preview dashboard shell.

M2 · Google Authentication NEXT / READY

Google OAuth single sign-on, session restoration, private route protection, and user profile display.

M3 · Private Task Storage PLANNED

Database schema, authenticated owner ID, Row-Level Security isolation, and typed data access.

M4 · Core Task Lifecycle PLANNED

Centered create modal, view & edit, confirmation before completion, quick Undo, and on-time vs. late audit.

M5 · Dashboard & Derived Views PLANNED

Calculated sections (Home, Today, Upcoming, Needs Attention, Completed, Archived) and calm 5/3/3/3 caps.

M6 · Search & Filters PLANNED

Keyword search across title and description, priority presets, deadline ranges, and clear-all action.

M7 · Archive & Reliability PLANNED

Reversible archiving, separately confirmed permanent deletion, offline handling, and error recovery.

M8 · Phase 1 Polish & Release Readiness PLANNED

Mobile responsiveness adaptation, accessibility compliance (WCAG AA), full automated test suite, and release sign-off.
